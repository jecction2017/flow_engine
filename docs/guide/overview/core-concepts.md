# 核心概念

## 概述

以下概念在界面与文档中反复出现，建议先建立统一理解。

## Flow（流程）

一次业务编排的完整定义，包含节点树、执行策略、初始上下文等。在 Flow Studio 中编辑，以**草稿**保存，**提交**后产生不可变**版本号**（V1、V2…）。

## Node（节点）

流程中的执行单元，类型包括：

- **task** — 执行脚本的任务
- **loop** — 对集合迭代，可含子节点
- **subflow** — 子流程容器，可含子节点

## Profile（环境）

一组配置（数据字典覆盖、能力策略等）的名称，如 `default`、预发、生产。试运行与部署时需选择 Profile。

## Deployment（部署）

把某个流程**指定版本**绑定到 Profile、运行模式与调度方式，由 Worker 拉取执行。生产行为通过部署触发，而非试运行入口。

## RunMode（运行模式）

- **debug** — 调试/试运行/测试中心固定使用；默认抑制副作用类内置函数
- **shadow** — 影子运行
- **production** — 生产运行
