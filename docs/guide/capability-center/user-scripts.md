# 用户脚本

## 概述

在 **能力与脚本 → 用户脚本** 管理可复用的 `.star` 模块，路径形如 `模块/名称.star`，URI 为 `user://租户/模块/名称.star`。

## 操作步骤

1. 左侧添加 **模块**，再在模块下 **添加脚本**。
2. 编辑脚本内容，使用 **保存**（仅用户脚本分区可写）。
3. 在任务节点脚本中 `load("user://...", "...")` 引用导出符号。
