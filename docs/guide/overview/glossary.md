# 术语表

| 术语 | 含义 | 常见界面位置 |
|------|------|----------------|
| Flow / 流程 | 编排定义 | Flow Studio |
| 草稿 / 版本 | 未提交编辑态 / 已提交 Vn | Flow Studio 顶栏 |
| 试运行 | 单次调试执行 | Flow Studio → 试运行面板 |
| Profile / 环境 | 配置集合名 | 环境配置、试运行、部署 |
| 部署 | 版本+环境+调度的运行绑定 | 运行中心 |
| Worker | 执行部署的进程 | 运行中心 → 工作节点 |
| 能力策略 | 对副作用 builtin 的 allow/suppress/redirect 规则 | 环境配置、部署、节点、试运行折叠区 |
| 本次附加策略 | 仅当前一次请求生效的策略 | 试运行、节点调试、脚本调试 |
| Lookup | 表格式配置/测试数据 | Lookup Tab |
| 数据字典 | YAML 模块树配置 | 数据字典 Tab |
| global_ns | 运行结束时的全局命名空间，断言对比对象 | 测试中心 |
| Starlark | 流程脚本语言（Python 风格子集） | 能力与脚本、节点编辑器 |
