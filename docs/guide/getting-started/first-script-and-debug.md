# 第一次写脚本并调试

## 概述

在能力与脚本中创建用户脚本，调试通过后再挂到 Flow Studio 任务节点。

## 操作步骤

1. **能力与脚本 → 用户脚本**：添加模块与脚本文件。
2. 编写返回 dict 的脚本 — 见 [脚本快速开始](../scripting/quick-start.md)。
3. 打开 **调试**，填写调试上下文 JSON，执行并检查输出。
4. 在 Flow Studio 任务节点的脚本区域引用或粘贴逻辑，使用 **节点调试** 验证。

## 推荐调试步骤

1. 先返回 1～2 个简单字段，确保结构正确。
2. 在调试上下文里模拟输入数据。
3. 观察输出 JSON，逐步增加逻辑。
