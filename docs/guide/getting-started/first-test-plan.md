# 第一次配置测试

## 概述

在测试中心创建测试方案，绑定流程版本与 Lookup 测试数据，运行批次并查看断言结论。

## 操作步骤

1. **测试中心** 新建测试方案：选择流程、版本通道、测试 Lookup 命名空间、Profile。
2. 配置 **上下文映射** 与 **断言**（见 [断言规则](../test-center/assertions.md)）。
3. 创建批次并运行，查看每条用例 `verdict=pass/fail`。
